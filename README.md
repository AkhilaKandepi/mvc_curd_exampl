# MVC CRUD Example

## About the Project
This is a collaborative learning project developed using ASP.NET Core MVC to understand and practice CRUD operations.

CRUD stands for Create, Read, Update, and Delete. These operations help us manage data in a web application.

## Technologies Used
- C#
- ASP.NET Core MVC
- HTML and CSS
- SQL Server and Entity Framework Core (if used in this project)

## Learning Objectives
- Understand the MVC architecture.
- Implement CRUD operations.
- Learn how Controllers, Models, and Views work together.
- Practice database connectivity.
- Improve debugging and problem-solving skills.
